# Prompts

The briefs that were pasted into Claude Code sessions to build this project, kept as
written. They are part of the honest account of how Citable was made — see
[AI usage](../README.md#ai-usage) in the main README.

The prompts are in German, the language they were written in. Paths inside them refer to
the repository as it was on the day they were written; the working notes they mention now
live in [`../notes/`](../notes/).

| Prompt | Written | What it asked for | Outcome |
|---|---|---|---|
| [`BUILD.md`](BUILD.md) | 09.09.2026 | The base in one pass: leaf hashing with JS ↔ Solidity parity, the registry, the ENSv2 name guard, the deploy script | Done the same day; the Sepolia broadcast followed on 10.09. |
| [`REDESIGN.md`](REDESIGN.md) | 11.09.2026 | The website rebuilt from the ground up: newspaper tone, the hero, both doors on one page | Built; the hero went through several rounds, variants in [`../design/hero/`](../design/hero/) |
| [`SUBMISSION.md`](SUBMISSION.md) | 12.09.2026 | The video script and the ETHGlobal submission text, every number traced to a measurement | Brief for the final session |

The specification the prompts build on is [`../CONCEPT.md`](../CONCEPT.md). The session
entry point is [`../CLAUDE.md`](../CLAUDE.md).
